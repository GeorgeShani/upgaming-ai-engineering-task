# Fictional upload examples

These files describe no real incident. `incident.pdf`, `incident.docx`, and `incident.txt` have
equivalent normalized text, so uploading all three should produce one active document.
`incident-updated.txt` changes the recovery time from 12 to 8 minutes and should produce a new
revision when used with PUT on that document. These are manual ingestion fixtures, separate
from the frozen dataset evaluation pack.
